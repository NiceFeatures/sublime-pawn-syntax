# Pawn Syntax for Sublime Text

Modern Sublime Text 4 syntax highlighting for **AMX Mod X Pawn** (`.sma` and `.inc` files), including support for ReAPI, standard natives, preprocessor directives, and Pawn constructs.

## Features

- Full `.sublime-syntax` highlighting for AMX Mod X scripts.
- Supports `.sma`, `.inc`, and `.pwn` file extensions.
- Provides scope `source.pawn`.
- Compatible with Sublime Text 4 (Build 4000+).

## Installation

### Manual Installation
1. Clone or download this repository.
2. In Sublime Text, open **Preferences > Browse Packages...**.
3. Place this directory inside as `Pawn-syntax` (or `sublime-pawn-syntax`).

## LSP Support
For full autocomplete, diagnostics, go-to-definition, hover documentation, and compilation support, install **[LSP-pawnforge](https://github.com/NiceFeatures/LSP-pawnforge)**.
